# Design Guide

## 악보 만들기 화면 원칙

1. `/` 입력은 그대로 유지하고, 표시에서는 마디 경계처럼 보이게 한다.
   - 사용자 입력 포맷은 변경하지 않는다.
   - 슬래시(`/`) 위치만 옅은 하늘색으로 강조해 마디 경계를 빠르게 인식하게 한다.
2. 미리보기 선택은 입력 영역 줄 하이라이트로 연결한다.
   - 미리보기에서 마디를 선택하면 입력 영역에서 해당 줄을 강조한다.
   - 자동 스크롤 이동이나 위치 설명 텍스트는 사용하지 않는다.
   - 코드 입력 영역에는 선택 마디 위치를 약하게 힌트로 보여준다.
3. 미리보기 폭은 실제 A4 인쇄 폭과 최대한 일치시킨다.
   - 화면 미리보기와 인쇄/PDF 결과의 줄 길이 차이를 최소화한다.
   - A4 폭 기준(인쇄 여백 포함)을 미리보기와 print 스타일에 동일하게 반영한다.
